PDFx для Windows — переносная версия

ЗАПУСК
  Распакуйте архив в любую папку (можно на флешку) и запустите pdfx.exe.
  Установка, права администратора и интернет не нужны.

  Программа не подписана цифровой подписью: при первом запуске Windows
  SmartScreen может предупредить — «Подробнее» → «Выполнить в любом случае».

ДАННЫЕ
  Настройки и автоматически сохранённый сеанс (все вкладки) хранятся
  в папке data рядом с pdfx.exe. Чтобы перенести программу вместе с
  открытыми вкладками, скопируйте папку целиком.
  Если в папку программы нельзя писать, данные сохраняются в %APPDATA%\PDFx.
  Исходные PDF не изменяются и не копируются.

УПРАВЛЕНИЕ
  Колёсико ............ прокрутка вверх-вниз
  Shift + колёсико .... прокрутка влево-вправо
  Ctrl + колёсико ..... масштаб относительно курсора (на тачпаде — щипок)
  Средняя кнопка ...... перетаскивание холста
  Ctrl + 0 ............ вписать в окно
  Двойной щелчок ...... страница на весь экран (Edit — пометки и фигуры)
  Правый щелчок ....... меню страницы или документа
  Ctrl/Shift + щелчок . выделение нескольких страниц, Ctrl + A — всё
  Ctrl + Z / Ctrl + Y . отменить / повторить
  Ctrl + F ............ поиск (сканы распознаются локально, русский + английский)
  Ctrl + T / Ctrl + W . новая / закрыть вкладку, Ctrl + Tab — следующая
  Ctrl + Shift + S .... сохранить все вкладки в файл .pdfxs
  Ctrl + , ............ настройки (в том числе колёсико как в CAD)
  F1 .................. справка

ОБНОВЛЕНИЯ
  Раз в сутки PDFx проверяет новую версию (Help → Check for Updates —
  вручную). Новая версия заменяет файлы программы при перезапуске или
  закрытии, папка data остаётся. Прежнюю версию можно вернуть в About.
  Если в интернет пускают только браузер, PDFx предложит скачать ZIP
  в браузере и сам найдёт его в «Загрузках».

Подробнее: README.md в репозитории проекта.
