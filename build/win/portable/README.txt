PDFx for Windows — Portable

Запуск: распакуйте архив в любую папку и запустите pdfx.exe.
Установка и права администратора не нужны, интернет не требуется.

Настройки и сохранённые сеансы хранятся в папке data рядом с pdfx.exe.
Чтобы перенести программу, скопируйте папку целиком.
Если папка недоступна для записи, данные сохраняются в %APPDATA%\PDFx.

Программа не подписана цифровой подписью: при первом запуске Windows
SmartScreen может показать предупреждение — «Подробнее» → «Выполнить в любом случае».
