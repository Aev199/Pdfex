# Изменения относительно PDFx

Основа: [PDFx](https://github.com/AlexandrosGounis/pdfx), коммит `a8fc12d`
(версия 0.2.0 и последующие изменения основной ветки). Все функции оригинала
сохранены: OCR, поиск, текст, выделение, формы, подписи, скрытие текста,
экспорт `.pdfx`, ИИ-инструменты (без ключа скрыты).

## Windows Portable

- Сборка `PDFx-Windows-Portable.zip` в GitHub Actions: без установщика и
  реестра, проверка комплектности и пробный запуск `pdfx.exe` в CI.
- Данные хранятся в папке `data` рядом с `pdfx.exe`. Если туда нельзя
  писать, используется `%APPDATA%\PDFx` с предупреждением.
- Пути из командной строки и при повторном запуске разрешаются относительно
  папки запуска.
- Временные файлы для внешних программ удаляются при запуске и выходе.

## Навигация

- Колёсико мыши двигает холст плавно, Shift + колёсико — по горизонтали,
  Ctrl + колёсико плавно масштабирует относительно курсора (1,2× за
  щелчок, а не 2,8× рывком, как раньше).
- Тачпад: прокрутка двумя пальцами и щипок применяются непрерывно.
- Средняя кнопка перетаскивает холст из любой точки, в том числе поверх
  страницы. Автопрокрутка Chromium отключена.
- Кнопки и клавиши масштаба тоже работают плавно.
- Во весь экран: те же правила колёсика, предел приближения поднят с 8× до
  32× для чертежей.
- «Вписать» для длинных документов показывает первые ~15 страниц, а не
  весь ряд в 4%.

## Документы (перенесено из PDFx Plus и адаптировано)

- Контекстные меню страницы и документа: дублировать, копировать,
  разделить, извлечь, экспортировать страницу, выделение или документ,
  заменить файлом, перенести во вкладку, открыть во внешней программе,
  показать в Проводнике, удалить.
- Выделение Ctrl/Shift + щелчок, Ctrl + A, Ctrl + D.
- Отменить и повторить можно любое изменение списка документов (в
  оригинале только перемещения страниц и пометки). Добавлено Ctrl + Y.
- Выбор документов при **Export PDF**.
- Строка сведений о документе при наведении: имя, страницы, размер, папка,
  даты файла.
- Заглушки строк, пока файлы импортируются.
- Заголовки документов увеличиваются до 2× при отдалении; длинные имена
  получили больше места.
- Номер документа можно перетащить в Проводник и получить PDF.
- Тёмная тема закреплена явно: на Linux Chromium игнорировал выбор темы
  и рисовал тёмный текст на тёмном фоне.

## Вкладки и сеансы

- Вкладки с независимыми документами, пометками, формами, историей
  отмены, выделением и положением холста. Переименование, цвет,
  Ctrl + T, Ctrl + W, Ctrl + Tab.
- Неактивные вкладки хранятся как данные без отрисованных страниц.
- Перенос документов между вкладками вместе с пометками.
- Автосохранение всех вкладок через секунду после изменения и при
  закрытии окна. Запись атомарная, предыдущая версия хранится как
  резервная; после аварийного завершения сеанс восстанавливается.
- Файлы `.pdfxs` (Save Session As / Save Tab As): ZIP с описанием сеанса;
  пути к PDF хранятся и абсолютные, и относительно файла сеанса.
- Исходные PDF не копируются: хранятся путь, размер и дата изменения.
  Копируется только то, чего нет на диске.
- Отсутствующие файлы: уведомление с кнопками «Locate…» (страницы
  возвращаются на место) и «Remove».
- Файлы, изменённые другой программой, обнаруживаются при возврате в окно
  и каждые 15 секунд; кнопка «Reload» сохраняет пометки и отменяется.
- Неизменённые PDF больше не держатся в памяти второй копией: экспорт
  перечитывает файл, а изменённый или перемещённый файл отклоняется с
  понятным сообщением.

## Пометки

- Новые инструменты в системе элементов оригинала: перо, линия, стрелка,
  прямоугольник, эллипс, ластик. Шесть цветов, четыре толщины, Shift для
  45° и квадратов. Экспорт в виде векторной графики PDF.
- Подпись (Sign), текст, выделение и скрытие текста работают как прежде.

## OCR и поиск

- Добавлен русский язык (`rus`, локально), по умолчанию «Russian +
  English».
- «ё» и «е» при поиске не различаются.
- OCR сканов запускается при первом поиске (или запросе ИИ), а не сразу
  при импорте.
- Результаты OCR не теряются при переключении вкладок.
- Исправлена ошибка оригинала: правило CSP блокировало стандартные шрифты
  PDF.js, из-за чего PDF без встроенных шрифтов отображались подставными
  глифами.

## Производительность

- Размер растра страницы выбирается по размеру на экране (160 / 320 / 640 /
  1100 px), а не всегда 1100 px. Детализация при приближении
  перерисовывается только для видимой части.
- Общая очередь отрисовки: сначала видимые страницы, не более 3
  одновременно, задачи для уже пролистанных страниц отбрасываются.
- Растры страниц, ушедших с экрана, освобождаются; кэши PDF.js очищаются в
  простое; документы, недоступные ни из одной вкладки, истории отмены или
  буфера обмена, закрываются.
- Масштабирование не перерисовывает всё приложение: процент масштаба
  вынесен в отдельное хранилище.

Замеры приведены в [docs/TEST-REPORT.md](docs/TEST-REPORT.md).
